# Sistem Inventaris Barang

Proyek UTS Pemrograman Web 1: aplikasi web sederhana untuk mencatat dan mencari data barang.

**Nama:** Dhafin Fadhilah
**NIM:** 17241029

## Fitur
- Menambah data barang (PHP, metode POST)
- Mencari barang berdasarkan kode, nama, atau kategori (PHP, metode GET)
- Menampilkan data barang dalam tabel
- Validasi form real-time (JavaScript)
- Validasi data di server (PHP)
- Tampilan responsif dengan pendekatan mobile-first

## Teknologi
HTML5, CSS (Flexbox dan Grid), JavaScript, dan PHP

## Struktur Folder
```
inventaris/
├── index.php
├── css/
│   └── style.css
├── js/
│   └── script.js
├── docs/
│   └── (laporan proyek)
└── README.md
```

## Cara Menjalankan
1. Instal XAMPP.
2. Salin folder proyek ke `htdocs` dengan nama `inventaris`.
3. Jalankan Apache di XAMPP Control Panel.
4. Buka `http://localhost/inventaris/` di browser.

## Catatan
Data disimpan sementara menggunakan PHP session, belum menggunakan database.
